Indian Army Pension Calculator — v3 (detailed)
This is a static site ready to host on GitHub Pages.
Features:
- Estimates Basic Pension, DA, MSP, Gratuity (with ₹20L cap shown), Commutation (lump sum & post-commutation pension), Family Pension.
- MSP presets for OR/JCO and Officers (editable).
- Informational only — verify with official pension authorities.

Key formulas & sources (for reference used in UI):
- Basic pension = 50% of emoluments (Basic + MSP) or average of last 10 months — Department of Ex-Servicemen Welfare / pension rules.
- Gratuity (common central formula) used: (15/26) × Last Basic × Years. Latest gratuity ceilings may apply.
Sources: DESW pension page, gratuity calculators, 7th CPC summary.

To deploy:
1. Unzip and push files to a GitHub repo.
2. Enable Pages from repository settings (use main branch / root).
3. Replace army_logo.png with a proper image (ensure you have rights to use it).
